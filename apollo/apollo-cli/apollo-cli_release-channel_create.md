apollo-cli release-channel create [Experimental] This command is Experimental. To enable this command, run the apollo-cli configure command and enable V2 experimental commands. Create a new release channel. Creates a new release channel with the given name and description. Example: Create a release channel. apollo-cli release-channel create MY_CHANNEL --description "My custom release channel" Create a release channel with a label requirement (label must exist, no specific value required). apollo-cli release-channel create MY_CHANNEL --description "Requires security scan" --label-requirement "vulnerability-scanner.palantir.build/security-scanned" Create a release channel with a label requirement (label must have specific value). apollo-cli release-channel create MY_CHANNEL --description "Requires specific approval" --label-requirement-value "approval.palantir.build/approved=true" Use --space-id for omniscient mode. apollo-cli release-channel create MY_CHANNEL --description "My channel" --space-id my-space-id. 1 apollo-cli release-channel create <channel-name> [flags] Flags. FlagUse --description. Description of the release channel (required). -h, --help. Help for create. --label-requirement. Label ID that must exist on product releases (can be specified multiple times). --label-requirement-value. Label ID with required value in format 'labelId=value' (can be specified multiple times). Flags inherited from parent commands. FlagUse --apollo-client-id. Client ID to use for generating Bearer Token. --apollo-client-secret. Client secret to use for generating Bearer Token. --apollo-token. Bearer Token to use for authenticated endpoints. --apollo-token-provider. Specifies how the Bearer Token used for authenticated Apollo endpoint calls is provided. Valid values are "auto", "static", or "service-user" (default "auto"). If "auto" is specified, will use either the Bearer Token provided by "apollo-token" or a Bearer Token obtained by using "apollo-client-id" and "apollo-client-secret" to generate a token from Multipass depending on which values are set (but will error if both values are set). If "static" is specified, the token provided by "apollo-token" is used. If "service-user" is specified, "apollo-client-id" and "apollo-client-secret" are used to generate a token from Multipass. --apollo-url.
