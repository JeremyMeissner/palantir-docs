# apollo-cli product-release get

Get one or more product releases. Get one or more product releases by maven coordinate. When a single coordinate is provided, the release is printed in YAML format. When multiple coordinates are provided, results are displayed in a table. Example: apollo-cli product-release get com.palantir.product:foo:1.0.0 apollo-cli product-release get com.palantir.product:foo:1.0.0 com.palantir.product:bar:2.0.0. If you want to get product-releases in an enrollment you are not a member of the primary org for, set the spaceID using the global '--space-id' flag. 1 apollo-cli product-release get <maven-coordinate> [maven-coordinate...] [flags] Flags. Specifies how the Bearer Token used for authenticated Apollo endpoint calls is provided. Valid values are "auto", "static", or "service-user" (default "auto"). If "auto" is specified, will use either the Bearer Token provided by "apollo-token" or a Bearer Token obtained by using "apollo-client-id" and "apollo-client-secret" to generate a token from Multipass depending on which values are set (but will error if both values are set). If "static" is specified, the token provided by "apollo-token" is used.
