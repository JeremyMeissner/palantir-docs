# Teams

This section will walk through the settings workflows to create a new team in Apollo. This is an administrative workflow accessible only to Apollo administrators. Before reading this section, read more about how teams power authorization in the Apollo platform. You can access team settings through the Hub Settings page via the Settings icon at the bottom of the workspace navigation bar. Select the Teams navigation option to show several workflows available for managing teams. From the teams settings panel, you can: Create a new team. View or edit existing teams. Set up team contacts.
