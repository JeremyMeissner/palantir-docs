# Product Types

Product types dictate how Apollo interprets a product's distribution and manages a product's deployment. Apollo supports different features of deployment by product type. Product types are declared in a Product's Manifest. Supported Product Types. Assets. Apollo interprets Products with the asset.v1 product type as an arbitrary set of files. Helm Charts. Apollo interprets Products with the helm.v1 product type as Helm Chart ↗ distributions.
