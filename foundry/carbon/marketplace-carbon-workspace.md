# Add Carbon workspace to a Marketplace product

Use Foundry DevOps to include your Carbon workspaces in Marketplace products for other users to install and reuse. Learn how to create your first product. Supported features. Many Carbon features are supported with the exception of: Walkthroughs (coming soon). Module types that are not Workshop, object type, or "Link to Foundry Application" Using groups for "Default object types for search" "Select objects" item type. Adding Carbon workspaces to products. To add a Carbon workspace to a product, first create a product, then add outputs. Choose the Add files option to navigate to the workspace from within the Compass filesystem and add it to your product.
