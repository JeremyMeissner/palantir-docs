# Duplicate a report

The Foundry Reports application has been sunsetted, and legacy reports are now available as view-only. Refer to the Reports sunset announcement for further details. There are several ways to duplicate a report; each is described below. Via the Report. Open the Actions menu. Click Duplicate report. Via the Application header. Open the File menu. Click Duplicate file. Via Your files view. As with any resource in Palantir Foundry—whether a report or something else—you can duplicate a report while viewing the resources in a Project: Right click on the report in your list of files. Click Actions in the context menu that appears. Click Duplicate report.
