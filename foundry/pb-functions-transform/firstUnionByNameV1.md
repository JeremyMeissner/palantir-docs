First union by name. Supported in: Batch, Faster. Unions a set of datasets together on columns from the first dataset, adding nulls when columns are missing. Columns that are not present in the first dataset are removed. Transform categories: Join. Declared arguments. Datasets to union: The datasets being unioned together. List<Table> Examples.
