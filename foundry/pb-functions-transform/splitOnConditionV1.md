# Split on condition

Supported in: Batch, Faster. Split an input into two outputs based on chosen condition. Transform categories: Other. Declared arguments. Condition: Rows where this condition is true will be split into the true output, and rows where this condition is false will be split into the false output. Expression<Boolean> Input: The input to split. Table.
