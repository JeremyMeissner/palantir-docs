Join. Supported in: Batch, Faster, Streaming. Joins left and right dataset inputs together. Transform categories: Join. Declared arguments. Join key: A list of columns from left and right input to join on. List<Tuple<Column<AnyType>, Column<AnyType>>> Join type: The type of join to perform. Enum<Anti join, Cross join, Full outer join, Inner join, Left join, Right join, Semi join> Left dataset: Left dataset to use in join. Table. Right dataset: Right dataset to use in join. Table.
