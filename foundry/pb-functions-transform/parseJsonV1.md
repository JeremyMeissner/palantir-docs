Extract rows from a JSON file. Supported in: Batch. Reads a dataset of files and parses each JSON file into rows. Transform categories: File, String, Struct. Declared arguments. Allow JSON values to span multiple lines: If off, a single JSON record must be entirely on one line. If on, a single JSON record may span multiple lines. Literal<Boolean> Dataset: Dataset of files to process. Files. Schema: Schema definition used when parsing the JSON files. Type<Struct>
