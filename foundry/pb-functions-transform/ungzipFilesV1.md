# Decompress gzip files

Supported in: Batch. Decompress each file in a dataset of gzipped files. Note that users must have editor permission to be able to preview the unarchive file transform and all downstream nodes. Transform categories: File. Declared arguments. Dataset: Dataset of files to process. Files.
