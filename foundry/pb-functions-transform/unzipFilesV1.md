Unzip files. Supported in: Batch. Unzips each file in a dataset of zipped files. Any non-zip files are ignored. Note that users must have editor permission to be able to preview the unzip file transform and all downstream nodes. Transform categories: File. Declared arguments. Dataset: Dataset of files to process. Files.
