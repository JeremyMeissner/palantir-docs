# Cipher decrypt

Supported in: Batch, Faster, Streaming. Decrypts expression with cipher. Expression categories: Other. Declared arguments. Cipher license rid: Cipher license to use. ResourceIdentifier. Expression: Expression to apply cipher decryption on. Expression<String> Output type: String. Examples. Example 1: Base case. Example 2: Null case. Argument values: Cipher license rid: ri.bellaso.main.cipher-license.1-decrypt. Expression: string. stringOutput null. null.
