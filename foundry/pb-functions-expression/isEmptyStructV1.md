# Is empty struct

Supported in: Batch, Streaming. Returns true if the input is an empty struct, with recursive checking of inner arrays and structs. Expression categories: Boolean. Declared arguments. Expression: Compute whether this struct is empty or has non-null fields. Expression<Struct> Output type: Boolean. Examples. Example 1: Base case.
