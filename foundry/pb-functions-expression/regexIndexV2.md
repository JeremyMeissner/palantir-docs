# Regex index

Supported in: Batch, Faster, Streaming. Returns an array of indices (counted as Unicode code points) at which the regular expression pattern is found in the given expression. Expression categories: Regex, String. Declared arguments. Expression: The expression to match against the regular expression. Expression<String> Regex: The regular expression to find indices for. Expression<String> Output type: Array<Integer> Examples. Example 1: Base case. Description: You can find regex patterns and their indices. Argument values: Expression: ababab. Regex: ab.
