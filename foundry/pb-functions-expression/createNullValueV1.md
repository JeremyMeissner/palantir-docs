Type: The type of the null value to create. Type<T> Type variable bounds: T accepts AnyType. Output type: T. Examples. Example 1: Base case. Argument values: Type: Array<String> Output: null. Example 2: Base case. Argument values: Type: Map<String, String> Output: null. Example 3: Base case. Argument values: Type: String. Output: null. Example 4: Base case.
