Parse well known text as geometry. Supported in: Batch, Faster, Streaming. Converts well-known text (WKT) string to geometry logical type. Invalid WKT input will be returned as null. Optionally supply a source coordinate system identifier to convert from the source coordinate system to WGS 84 if the WKT is not in WGS 84 already. Expression categories: Geospatial. Declared arguments. Expression: Valid well-known text as a string. Expression<String> optional Source coordinate system: Optional coordinate system identifier if the well-known text is not WGS 84. Formatted as "authority". For example, UTM zone 18N could be identified by EPSG:32618. Literal<String> Output type: Geometry. Examples. Example 1: Base case. Argument values: Expression: wkt.
