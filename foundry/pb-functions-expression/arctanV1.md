# Arctan

Supported in: Batch, Faster, Streaming. Inverse tangent function. Expression categories: Numeric. Declared arguments. Angle unit: Output angle unit which is either degrees or radians. Enum<Degrees, Radians> Value: The value to compute arctan on. Expression<Double | Float> Output type: Double. Examples. Example 1: Base case. Argument values: Angle unit: degrees. Value: angle. angleOutput -1.0. -45.0. 0.0. 0.0. 1.0. 45.0. Example 2: Null case. Argument values: Angle unit: radians. Value: null. Output: null.
