# Cosine

Supported in: Batch, Faster, Streaming. Takes the cosine of an angle. Expression categories: Numeric. Declared arguments. Angle unit: Angle unit which is either degrees or radians. Enum<Degrees, Radians> Angle value: Angle value in either radians or degrees. Expression<DefiniteNumeric> Output type: Double. Examples. Example 1: Base case. Argument values: Angle unit: degrees. Angle value: angle. angleOutput 0.0. 1.0. 90.0. 0.0. 180.0. -1.0. Example 2: Null case. Argument values: Angle unit: radians. Angle value: null. Output: null.
