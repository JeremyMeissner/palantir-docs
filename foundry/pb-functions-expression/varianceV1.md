# Variance

Supported in: Batch, Streaming. Calculate population variance of values in column. Expression categories: Aggregate. Declared arguments. Expression: The column of on which variance is computed. Expression<Numeric> Output type: Double. Examples. Example 1: Base case. Argument values: Expression: values. Given input table: values 2. 4. 3. Outputs: 0.66666666667. Example 2: Null case. Argument values: Expression: values. Given input table: values 2. null. 3. Outputs: 0.25.
