# Convert legacy OffsetDateTime

Supported in: Batch. Converts a legacy OffsetDateTime column to a timestamp that can be used in all Foundry pipelines. The timestamp is returned in UTC. Expression categories: Datetime. Declared arguments. Expression: no description Expression<Struct<timestamp, offset>> Output type: Timestamp.
