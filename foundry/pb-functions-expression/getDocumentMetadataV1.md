Extract document metadata. Supported in: Batch, Faster. Extracts metadata fields from a document. Expression categories: Media. Declared arguments. Media reference: The column containing media references to PDF files in a media set. Expression<Media reference> Metadata to include: Select the metadata columns to include in the output. Set<Enum<Bytes, Document author, Document title, Page count>> Output type: Struct. Examples. Example 1: Base case. Argument values: Media reference: Media Reference.
