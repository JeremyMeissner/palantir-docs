# Logarithm

Supported in: Batch, Faster, Streaming. Calculates the natural logarithm, ln(x), of a column. Expression categories: Numeric. Declared arguments. Expression: Expression to calculate natural logarithm of. Expression<Numeric> Output type: Double. Examples. Example 1: Base case. Argument values: Expression: 10.123. Output: 2.3148100626166146. Example 2: Null case. Argument values: Expression: null. Output: null.
