# Create geotemporal series reference

Supported in: Batch, Streaming. Generate the required values for a geotemporal series reference object property type, which consists of a reference to a series of geotemporal observations and the RID to the geotemporal series integration that contains the series. Expression categories: Geospatial, Other, String. Declared arguments. Geotemporal series integration RID: The RID of the geotemporal series integration to reference. ResourceIdentifier. Series ID: The column with the series ID values that correspond to series in the geotemporal integration. Expression<String> Output type: Geotemporal series reference. Examples. Example 1: Base case.
