Array sort by struct key. Supported in: Batch, Streaming. Returns a sorted array of the given input array of structs sorted by the values of the given struct keys. Expression categories: Array. Declared arguments. Input array: Input array of structs to be sorted. Expression<Array<Struct>> Sort keys: Struct keys to sort array by in order of sort priority. Sort nested struct elements with multiple entries like ['author', 'age']. List<Tuple<StructLocator, Enum<Ascending, Descending>>> Output type: Array<Struct> Examples. Example 1: Base case. Argument values: Input array: [ { age: 20, }, { age: 10, }, { age: 30, } ] Sort keys: [(age, ASCENDING)] Output: [ { age: 10, }, { age: 20, }, { age: 30, } ] Example 2: Base case.
