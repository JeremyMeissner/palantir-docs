# Product

Supported in: Batch. Calculates the product of all input columns. Expression categories: Numeric. Declared arguments. Expression: no description Expression<Numeric> Output type: Double. Examples. Example 1: Base case. Argument values: Expression: factor. Given input table: factor 2. 4. 3. Outputs: 24.0. Example 2: Base case. Argument values: Expression: factor. Given input table: factor 2. null. 3. Outputs: 6.0.
