Get bearing from start point to end point. Supported in: Batch, Faster, Streaming. Calculates the absolute true bearing (clockwise angle relative to geographical north) from the first point to the second point in degrees using a spherical approximation of the earth. Expression categories: Geospatial. Declared arguments. Ending point: Longitude and latitude for the ending point. Expression<GeoPoint> Starting point: Longitude and latitude for the starting point. Expression<GeoPoint> Output type: Double. Examples. Example 1: Base case. Argument values: Ending point: end_point.
