Rank. Supported in: Batch, Faster. Returns the rank of rows within a window partition. In case of ties the rows get same rank. The difference between rank and dense_rank is that rank leaves gaps in ranking sequence when there are ties. Expression categories: Aggregate. Declared arguments. This function does not take any arguments. Output type: Integer.
