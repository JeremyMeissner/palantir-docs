# Length

Supported in: Batch, Faster, Streaming. Returns the length of each value in a string column or an array column. Expression categories: Array, Numeric. Declared arguments. Expression: The expression to compute the length of. Expression<Array<AnyType> | Binary | Map<AnyType, AnyType> | String> Output type: Integer. Examples. Example 1: Base case.
