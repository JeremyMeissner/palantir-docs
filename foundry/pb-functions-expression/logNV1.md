# Logarithm with base

Supported in: Batch, Faster, Streaming. Calculates logarithm with a given base. Expression categories: Numeric. Declared arguments. Base: no description Literal<Double> Expression: no description Expression<Numeric> Output type: Double. Examples. Example 1: Base case. Argument values: Base: 2.0. Expression: 8. Output: 3.0. Example 2: Null case. Argument values: Base: 2.0. Expression: null. Output: null.
