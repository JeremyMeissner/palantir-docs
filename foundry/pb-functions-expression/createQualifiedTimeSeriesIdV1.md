# Create time series reference values

Supported in: Batch, Streaming. Creates time series reference values. Expression categories: String. Declared arguments. Series identifier: The series identifiers contained in the time series sync. Expression<String> Time series sync RID: The resource identifier (RID) of the time series sync containing the series identifiers. Expression<String> Output type: String. Examples. Example 1: Base case. Argument values: Series identifier: seriesId. Time series sync RID: ri.time-series-catalog.main.sync.11111111. seriesIdOutput seriesOne. {"seriesId":"seriesOne","syncRid":"ri.time-series-catalog.main.sync.11111111"} Example 2: Base case. Argument values: Series identifier: seriesId. Time series sync RID: syncRid. seriesIdsyncRidOutput seriesOne. ri.time-series-catalog.main.sync.11111111. {"seriesId":"seriesOne","syncRid":"ri.time-series-catalog.main.sync.11111111"} seriesTwo. ri.time-series-catalog.main.sync.22222222. {"seriesId":"seriesTwo","syncRid":"ri.time-series-catalog.main.sync.22222222"} Example 3: Null case. Argument values: Series identifier: seriesId. Time series sync RID: ri.time-series-catalog.main.sync.11111111. seriesIdOutput null. {"seriesId":"null","syncRid":"ri.time-series-catalog.main.sync.11111111"} Example 4: Null case. Argument values: Series identifier: seriesId. Time series sync RID: null. seriesIdOutput seriesOne. {"seriesId":"seriesOne","syncRid":"null"}
