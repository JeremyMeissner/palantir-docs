Source exploration. Once the source has been created, the SDDI SAP Source Explorer can be used for interactive source exploration. Note that all data in the following screenshots is notional. Navigate to the source and select the Explore and create syncs button. For remote and SLT connections, select the appropriate context. Select the tables or modules of interest and add them onto the graph. Proceed to configuring the syncs.
