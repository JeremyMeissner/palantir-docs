Integrations. Global Branching integrates with applications across the platform, enabling isolated development workflows for a wide range of resources. While the Global Branching application provides a unified experience across the Palantir platform for common operations like adding resources, rebasing, and merging, the details vary depending on which Foundry application you are working in. The documentation below covers application-specific details for working with branches, including how to add and modify resources, cross-application compatibility, rebase behavior, and any known limitations.
