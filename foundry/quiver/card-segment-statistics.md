# Segment statistics

Segment statistics operate on the output of a filtered series. Filtered series will often be shown as discrete segments, with gaps in between each segment. The Segment statistics allows you to calculate statistics about each segment (such as average, max, or standard deviation). Sunset. The segment statistics card is in the sunset phase of development and is no longer being updated. We recommend using the event statistics card instead. Input type. Time series. Output type.
