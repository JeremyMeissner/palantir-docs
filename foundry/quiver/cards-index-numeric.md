# Numeric cards

Back to: Index of cards. Cards in this section return and display numbers. The following cards accept object sets and return a single number: Numeric aggregation. The following cards accept single objects and return a single number: Object property. The following cards accept transform tables and return numbers: Transform table aggregation. Transform table column values. The following cards accept other numbers and return a single number: Numeric formula. Ceiling. Floor. The following cards accept dates and return a single number: Date difference. Day of month. Day of week. Hour of day. Month. Year. Day of year. The following cards accept time series and return a single number: Time series numeric aggregation. Value at time. Additional numeric cards include: Numeric parameter. String to number. Range start. Range end. Coalesce. Code function value. Numeric aggregation (materialization). Number array aggregation. Array length. Visual function metric. Array start. Array end. Value at index.
