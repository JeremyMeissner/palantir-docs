Numeric formula. Takes in numeric inputs and returns the result of a simple or complex math expression. These inputs can be any card of numeric type, such as object set aggregations, object property values, transform table aggregations, numeric outputs of code Functions, numeric parameters, or other numeric formula cards. You can reference other cards in the formula box by typing their global IDs ($A or $B, for example). If used as a transform inside of a transform table, columns can be referenced using @column notation. Input type. Number. Output type. Number. Usage information. FunctionalityAvailability Standard Quiver card. Supported. Transform table transform. Supported.
