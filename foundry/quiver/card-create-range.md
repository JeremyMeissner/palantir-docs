Create range. Create a new column in the transform table with a specified range value that is the same for all rows. Can be useful for hooking a range parameter's value into the transform table. Input type. Flow start, time, number. Output type. Number range, time range. Usage information. FunctionalityAvailability Standard Quiver card. Unsupported. Transform table transform. Supported.
