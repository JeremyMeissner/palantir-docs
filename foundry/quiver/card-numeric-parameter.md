Numeric parameter. Create a numeric input field which can be used as a variable in other cards that take a number as input. Examples include: Numeric properties filter values in the filter object set card. Inputs in formula cards, which can be useful as a way to quickly test different formula coefficients. Window duration value in the rolling aggregate card. Input type. Flow start. Output type. Number. Usage information. FunctionalityAvailability Standard Quiver card. Supported. Transform table transform. Unsupported.
