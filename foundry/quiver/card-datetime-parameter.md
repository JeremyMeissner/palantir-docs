# Date/time parameter

Create a date/time input field which can be used as a variable in other cards that take a time as input. Examples include: Date and timestamp property filter values in the filter object set card. Input to date markers on time series charts. Input to date markers on overlay charts. Input type. Flow start. Output type. Time. Usage information. FunctionalityAvailability Standard Quiver card. Supported. Transform table transform. Unsupported.
