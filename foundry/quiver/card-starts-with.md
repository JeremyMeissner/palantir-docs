# Starts with

Returns True if the input string starts with the specified substring (case-sensitive). Treats special characters such as ., /, @, -, and spaces as part of the literal search string, as oppose to the "contains" transform which uses special characters as word boundaries. Input type. String. Output type. Boolean. Usage information. FunctionalityAvailability Standard Quiver card. Supported. Transform table transform. Supported.
