# Array cards

Back to: Index of cards. Cards in this section return and display Array values. The following cards accept other arrays and return arrays: Array sort. Unique values. Strings to booleans. Strings to dates. Strings to numbers. Additional array cards include: Create array. String array parameter. Split. Stepped array. Code function value. Transform table column values. Code function value. The following cards accept time series as input: -Time series regression coefficients -Scatter plot regression coefficients.
