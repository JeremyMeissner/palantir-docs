# Value at time

Returns the value of an input numeric time series at a given input timestamp. If your time series values are strings, you must use the Enum value at time card. If you would like to return the first or last value of a numeric time series, you should use the Time series numeric aggregation card. To show the units of the series, use the Time series unit card.
