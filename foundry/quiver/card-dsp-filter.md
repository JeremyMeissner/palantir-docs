Digital Signal Processing (DSP) filter. DSP (digital signal processing) filters are commonly used on input series to reduce their noise. This is typically a more rigorous option to "smooth" a series than using a rolling aggregate. Quiver includes three separate filtering algorithms/prototypes: Butterworth ↗ Chebyshev ↗ Inverse Chebyshev ↗. For each algorithm, a filter response must be selected from the following options: Lowpass ↗ Highpass ↗ Bandpass ↗ Bandstop ↗ Input type. Time series. Output type. Time series. Example.
