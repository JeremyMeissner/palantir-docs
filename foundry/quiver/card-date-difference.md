# Date difference

Returns the difference between two dates in the specified unit. The available units are: Week. Day. Hour. Minute. Second. Millisecond. Input type. Time. Output type. Number. Usage information. FunctionalityAvailability Standard Quiver card. Supported. Transform table transform. Supported.
