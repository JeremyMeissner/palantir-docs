Multipass attribute. Returns the current user's Multipass attributes or the Multipass attributes associated with the input user ID. Possible attributes include: user ID, username, display name, given name, or family name. Input type. Flow start, string. Output type. String. Usage information. FunctionalityAvailability Standard Quiver card. Supported. Transform table transform. Supported.
