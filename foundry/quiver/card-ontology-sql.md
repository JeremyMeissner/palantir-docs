Ontology SQL. Beta. Ontology SQL is in the beta phase of development and some features may not be available on your enrollment. Refer to the Ontology SQL documentation for more information. The Ontology SQL card allows you to write SQL queries against object sets in your analysis. Using standard SQL syntax, you can select, filter, join, and aggregate object data to produce tabular results directly in Quiver. The Ontology SQL card accepts object sets and other Ontology SQL cards as inputs. Object set inputs are referenced in your SQL query as tables, while other Ontology SQL cards can be chained together to compose more complex queries. You can also pass scalar values such as dates, numbers, strings, and booleans as inputs to parameterize your queries. For a complete reference of available SQL operations, refer to the Ontology SQL documentation. The Ontology SQL card also supports AIP-powered SQL generation. You can describe the analysis you want to perform in natural language, and the card will generate a SQL query for you. Ontology SQL results can be converted to a transform table for further manipulation and charting. Input type. Object set, Ontology SQL, date, number, string, boolean. Output type. Ontology SQL.
