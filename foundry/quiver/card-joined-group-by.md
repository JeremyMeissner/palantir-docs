# Joined group by

Performs a group by operation, then joins the result onto the current transform table. This can be useful for comparison workflows, such as comparing each row against all rows in the specified group. Input type. Transform table. Output type. Transform table. Usage information. FunctionalityAvailability Standard Quiver card. Unsupported. Transform table transform. Supported.
