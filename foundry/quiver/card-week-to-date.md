# Week to date

Creates date range starting from 00:00 of the first day (either Monday or Sunday, as defined by user's locale) of input date's week to the input date. Input type. Time. Output type. Time range. Usage information. FunctionalityAvailability Standard Quiver card. Supported. Transform table transform. Supported.
