# Segment formula plot

Create a new categorical plot by applying formulas to specific segments shown in a categorical plot (for example, to scale certain segments by certain scalar values). Numbers, from aggregations or parameters, can also be in the formula. Input type. Categorical chart, number. Output type. Categorical chart, object selection. Usage information. FunctionalityAvailability Standard Quiver card. Supported. Transform table transform. Unsupported.
