Rename columns. Rename the display names for one or more columns in a transform table. Note that this transform will only update a column's display name; the transform will not change the column's underlying column ID. Input type. Transform table. Output type. Transform table. Usage information. FunctionalityAvailability Standard Quiver card. Unsupported. Transform table transform. Supported.
