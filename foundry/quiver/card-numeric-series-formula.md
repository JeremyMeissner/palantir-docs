# Numeric series formula

Generates a numeric series plot by writing a formula in the formula box. Note that the x-axis will be numeric. This card works well on scatter plots or distributions. It should not be used on time series charts. Input type. Number or object. Output type. Time series. Examples. Usage information. FunctionalityAvailability Standard Quiver card. Supported. Transform table transform. Unsupported. See also. Time series formula.
