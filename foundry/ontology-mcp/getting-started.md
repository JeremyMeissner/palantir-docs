# Getting started

To enable Ontology MCP (OMCP) for your application: Navigate to your application in Developer Console. Select the MCP page on the left side menu. Toggle the button on the top right to enable MCP server for your application. Use the configuration details listed on the page based on your selected agent framework. Even if your framework of choice is not listed, the configuration is likely similar assuming your framework can act as an MCP client. Once enabled, your application will expose its ontology resources as MCP tools. External MCP clients can connect to your application using the connection details shown in the settings panel. Ensure your application has the appropriate application restrictions configured to control which ontology resources are accessible through MCP.
