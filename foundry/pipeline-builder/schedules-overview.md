Schedules. Schedules in Pipeline Builder are used to run builds on a recurring basis. Configuring schedules is a vital part of ensuring pipeline data remain up-to-date for end users and downstream workflows. Scheduled builds can be configured to run: At certain times. When data has been updated. When logic has been updated. Any combination of the above conditions. Scheduled builds can be configured to build: A single dataset. A single dataset and all its dependencies. All datasets that depend on a dataset. All datasets that connect two datasets. Any combination of the above configurations. You can set up basic build schedules directly within Pipeline Builder and navigate to advanced settings and status reports in dataset views. Edit or remove schedules at any time, and review our best practices to optimize pipeline management. Learn how to create a schedule in Pipeline Builder, or learn more about viewing and modifying schedules in the dataset view.
