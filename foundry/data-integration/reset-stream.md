Reset stream. Resetting an ingest stream clears the existing records from a stream and provides an opportunity to change the stream's schema, throughput, and configuration values. This can be helpful during stream pipeline development since you can clear and update an ingest stream without replacing existing references of the stream within your Pipeline Builder pipelines. Note that resets are only available for ingest streams. Downstream consuming pipelines of the ingest stream must be replayed after a reset. Push-based ingestion requires updating the POST URL to reference the new stream viewRid value. Magritte-based ingestion requires an agent rebuild. Resetting streams can have irreversible effects on data. We do not recommend resetting production ingest streams because existing records will be lost. To reset a stream, follow the instructions below: Open an ingest stream. Select the Details tab. In the Stream Settings section, select Reset stream. You will be redirected to the stream reset page. On this page, you can optionally update the schema, throughput, or configuration values. If you only want to clear data from the stream, leave those sections unchanged. Select Reset stream to initiate the stream reset.
