Import XLS documents. You can convert an existing Excel file (.xls or .xlsx) to a Fusion spreadsheet by dragging and dropping into any folder in Foundry or through the New from Excel file option under the Document tab. The amount of data you can paste into a Fusion spreadsheet scales with your computer's memory, and typically works up to a few thousand rows. Use XLS Import to import larger files.
