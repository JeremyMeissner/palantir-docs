# foundryts.nodes.SummarizerNode

class foundryts.nodes.SummarizerNode(children). Lazy query container for summarizing one or more FunctionNode to a final result. A SummarizerNode is the final evaluated form of a raw or transformed time series and cannot be transformed by FoundryTS any further. It is typical to evaluate a SummarizerNode to a dataframe using either SummarizerNode.to_pandas() or SummarizerNode.to_dataframe() and performing transformations and analysis using the respective dataframe libraries. All series identifiers used by this node and its child nodes. to_dataframe(fts=None). Evaluates this node to a pyspark.sql.DataFrame. PySpark DataFrames enable distributed data processing and parallelized transformations. They can be useful when working with dataframes with a large number of rows, for example loading all the points in a raw series or the result of a FunctionNode, or evaluating the results of multiple SummarizerNode or FunctionNode together.
