# Models

You can create and iterate on Foundry Model Assets in Code Repositories and Code Workspaces. A Foundry Model is a "container for logic" - an object which encodes knowledge about your data to create predictions and empower decisions. Models can be saved for later use, providing lineage, history, security, and branching. Learn more about creating models in Code Repositories, creating models in Code Workspaces, and machine learning and modeling in Foundry.
