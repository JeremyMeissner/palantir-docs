# Tableau

The Foundry integration for Tableau offers the following: Enables you to easily create Tableau interactive dashboards backed by Foundry data. Supports both Extracts and Live Connections. Compatible with Foundry access controls, including granular permissions. Supported Tableau products. Tableau Desktop (2019.4 release or later). Tableau Server (2019.4 release or later). Note that Tableau Online via Tableau Bridge is not currently supported by the Tableau custom connector. We anticipate that support for the connector will become available with future releases of Tableau. Getting started. Setup Guide. Creating an Interactive Dashboard with Foundry Data. Learn more about Tableau in Tableau's official documentation.
