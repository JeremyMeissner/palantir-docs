# Add Vertex graph template to a Marketplace product

Use Foundry DevOps to include your Vertex graph templates in Marketplace products for other users to install and reuse. Learn how to create your first product. Supported features. All Vertex graph template features are supported with the exception of saved Search Arounds. Adding Vertex graph templates to products. To add a Vertex graph template to a product, first create a product, then add outputs. Choose the Add files option to navigate to the graph template from within the Compass filesystem and add it to your product.
