# View all recipes

All recipes can be viewed from the Recipes Management page in the Recipes application. Access the Recipes application from the Foundry navigation sidebar. Recipes are searchable via the search bar. The Your recipes tab of the Recipes application includes all recipes you have created or of which you are a recipient.
