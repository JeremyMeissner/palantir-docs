# Java transforms

Java transforms allow you to use common Java libraries for data transformation, and provides both high-level and low-level APIs for interacting with Foundry datasets. It includes support for batch and incremental pipelines and supports creating and sharing code libraries for reuse. Get started with Java transforms, or explore some of the available features: Java transforms and pipelines basics. Incremental Java transforms. Unit testing. Working with unstructured files. Sharing code. Advanced configuration.
