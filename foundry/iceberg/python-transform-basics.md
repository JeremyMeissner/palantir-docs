# Python transform basics

Iceberg tables can be used as inputs and outputs in Python transforms using the transforms.tables API, which can be imported in the transforms-tables package. This page provides code examples for the fundamentals of working with Iceberg table inputs and outputs in Python transforms. Example: Generate a simple Iceberg table.
