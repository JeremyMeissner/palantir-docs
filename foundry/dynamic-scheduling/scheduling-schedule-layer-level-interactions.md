Schedule layer-level interactions. Schedule layers are not only visually configurable, but can have their own customized set of interactions. As the same object type can be used across multiple schedule layers, this means you can create highly specific interaction definitions. You can use schedule layer-level interactions to enable users to modify certain properties of your schedule objects, create new schedule objects, or trigger events in your Workshop module. You can also customize the drag-and-drop behavior and granularity. These options are organized under the Drag & Drop and Interactions sub-sections within each schedule layer's configuration under Input Data (Pucks).
