Row-level interactions. Each row on the Scheduling Gantt chart represents a Resource object. Your Resource can for example, represent: Technicians for task assignment. Vehicles being scheduled for maintenance. Crew allocation for trips. You can use row-level interactions to enable users to modify certain properties of your row objects, create objects, or trigger events in your Workshop module.
