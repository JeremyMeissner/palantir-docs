# Output column metadata

Column metadata can be written on outputs alongside data from Python transforms. Update column descriptions in Code Repositories transforms. You can add column descriptions to your output datasets by providing the optional column_descriptions argument to the write_dataframe() function of the TransformOutput). This argument should be a dict ↗, with column names as keys and column descriptions as values. Column descriptions are limited to 800 characters in length. The code will automatically compute the intersection of column names available on your DataFrame ↗ and the keys in the provided dict, so descriptions will not be added on columns that do not exist.
