Object card. The Object card allows you to display multiple object properties with a link to the object. You can add it by clicking + Add Widget or typing / in a paragraph field to open up the widget insertion menu. By default, prominent properties will be shown. You can adjust the displayed properties and property order from Visible properties in the widget configuration panel on the right. Widget properties. Object selection: Object to display. Visible properties: Define which properties should be displayed and their order. Template configuration. Object selection: Object to display. Ontology Actions. Hover over a widget to display an Actions menu in the top-right corner that enables submitting Actions on the displayed object. Hover over properties with configured inline edits to display the edit option.
