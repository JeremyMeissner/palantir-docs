# Introduction

The Foundry API is a developer-friendly REST API for interacting with Palantir’s Foundry platform. It can be used to build applications on top of Palantir’s products. The Foundry API is a Representational State Transfer (REST) API consisting of HTTP endpoints. The endpoints use the OAuth 2.0 protocol for authentication and are designed in a common pattern, largely using JSON requests and responses. Refer to the Getting started page to begin using the APIs. Need to export data from Foundry? Data connection exports may be more suitable for your use case.
