Get Action Type. Gets a specific action type with the given API name. Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:ontologies-read. Path parameters. The unique Resource Identifier (RID) of the Ontology that contains the action type. The name of the action type in the API. Response body. Success response. The name of the action type in the API. To find the API name for your Action Type, use the List action types endpoint or check the Ontology Manager. The display name of the entity. The release status of the entity. Enum values: ACTIVE, ENDORSED, EXPERIMENTAL, DEPRECATED. The unique resource identifier of an action type, useful for interacting with other Foundry APIs. Examples.
