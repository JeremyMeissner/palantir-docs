Delete Branch. Deletes the Branch with the given BranchId. Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:datasets-write. Path parameters. The Resource Identifier (RID) of the Dataset that contains the Branch. The identifier (name) of the Branch. Examples. Error responses.
