# Create Export Job

## Endpoint

:::callout{theme=warning title=Warning}
  This endpoint is in preview and may be modified or removed at any time.
  To use this endpoint, add `preview=true` to the request query parameters.
:::

Creates a new ExportJob either from an existing Document or using the content generated by a GenerationJob.
If an ExportJob succeeds, it will produce a File that can be downloaded.

Third-party applications using this endpoint via OAuth2 must request the following operation scope: `api:notepad-export`.

**operationId:** v2.createExportJob

**path:** /api/v2/notepad/exportJobs/create

### Operation Type

### Scopes

| name |
| --- |
| api:notepad-export |

### Query Parameters

| name | type | required | description |
| --- | --- | --- | --- |
| preview | booleanType | False | Enables the use of preview functionality. |

### Request

#### Body

**name:** CreateExportJobRequest

##### Children

| name | type | required | description |
| --- | --- | --- | --- |
| exportJobSource | unionType | True | Defines the source of contents for an ExportJob |
| exportJobTarget | unionType | True | The target format that the job will export to. |

### Response

#### Body

**name:** ExportJob

**example:** {"rid":"ri.notepad.main.export-job.ef32c039-353c-4555-9704-eacfdfaa2c1c","status":{"type":"running"}}

##### Children

| name | type | required | description |
| --- | --- | --- | --- |
| rid | stringType | True | The unique identifier for an ExportJob |
| status | unionType | True | The status of an export job |

**example:** {"rid":"ri.notepad.main.export-job.ef32c039-353c-4555-9704-eacfdfaa2c1c","status":{"type":"running"}}

### Error Responses

| name | description |
| --- | --- |
| GenerationJobStatusFailed | The operation cannot be completed because the generation job has failed status. |
| GenerationJobStatusRunning | The operation cannot be completed because the generation job has running status. |
| DocumentNotFound | The requested document was not found. |
| ExportDocumentPermissionDenied | The user does not have export permissions on this Document. |
| ExportGenerationJobPermissionDenied | The user does not have export permissions on this GenerationJob. |
| InvalidExportJobUserLocale | The provided user locale is not valid. |
| InvalidTimezone | The provided timezone is not valid. |
| CreateExportJobPermissionDenied | Could not create the ExportJob. |
| GenerationJobNotFound | The given GenerationJob could not be found. |
