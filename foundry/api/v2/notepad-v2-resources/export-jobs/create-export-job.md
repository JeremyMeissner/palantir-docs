Create Export Job. Warning. This endpoint is in preview and may be modified or removed at any time. To use this endpoint, add preview=true to the request query parameters. Creates a new ExportJob either from an existing Document or using the content generated by a GenerationJob. If an ExportJob succeeds, it will produce a File that can be downloaded. Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:notepad-export. Query parameters. Enables the use of preview functionality. Request body. Defines the source of contents for an ExportJob. The target format that the job will export to. Response body. The unique identifier for an ExportJob. The status of an export job. Examples. Error responses.
