Get Agent Version. Warning. This endpoint is in preview and may be modified or removed at any time. To use this endpoint, add preview=true to the request query parameters. Get version details for an Agent. Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:aip-agents-read. Path parameters. An RID identifying an Agent created in AIP Chatbot Studio. The semantic version of the Agent, formatted as "majorVersion.minorVersion". Query parameters. Enables the use of preview functionality. Response body. The semantic version of the Agent, formatted as "majorVersion.minorVersion". Semantic version details of the Agent. Examples. Error responses.
