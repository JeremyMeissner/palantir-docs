Update Export Settings For Connection. Updates the export settings on the Connection. Only users with Information Security Officer role can modify the export settings. Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:connectivity-connection-write. Path parameters. The Resource Identifier (RID) of a Connection (also known as a source). Request body. The export settings of a Connection. Examples. Error responses.
