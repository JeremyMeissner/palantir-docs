Get Connection. Get the Connection with the specified rid. Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:connectivity-connection-read. Path parameters. The Resource Identifier (RID) of a Connection (also known as a source). Response body. The Resource Identifier (RID) of a Connection (also known as a source). The unique resource identifier (RID) of a Folder. The display name of the Connection. The display name must not be blank. The export settings of a Connection. The worker of a Connection, which defines where compute for capabilities are run. Examples. Error responses.
