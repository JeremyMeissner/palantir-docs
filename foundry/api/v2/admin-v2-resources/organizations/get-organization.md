# Get Organization

Get the Organization with the specified rid. Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:admin-read. Path parameters. Response body. The ID of this Organization's underlying marking. Organization guest access can be managed by updating the membership of this Marking. The primary host name of the Organization. This should be used when constructing URLs for users of this Organization. Examples. Error responses.
