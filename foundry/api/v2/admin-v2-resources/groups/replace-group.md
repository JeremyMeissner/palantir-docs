Replace Group. When replacing groups, you must send all attributes that begin with multipass: exactly as they appear when calling the Get Group endpoint. Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:admin-write. Path parameters. A Foundry Group ID. Request body. The name of the Group. The RIDs of the Organizations whose members can see this group. At least one Organization RID must be listed. A description of the Group. A map of the Group's attributes. Attributes prefixed with "multipass:" are reserved for internal use by Foundry and are subject to change. Response body. The replaced Group. A Foundry Group ID. The name of the Group. A description of the Group. Identifies which Realm a User or Group is a member of. The palantir-internal-realm is used for Users or Groups that are created in Foundry by administrators and not associated with any SSO provider.
