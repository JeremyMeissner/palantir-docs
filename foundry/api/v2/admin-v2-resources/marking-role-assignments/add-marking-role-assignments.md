Add Marking Role Assignments. Adds role assignments for the given Marking. For Organization markings, only the USE and DECLASSIFY roles are supported; the ADMINISTER role must be managed via the Organization Role Assignment endpoints. Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:admin-write. Path parameters. The ID of a security marking. Request body. Examples. Error responses.
