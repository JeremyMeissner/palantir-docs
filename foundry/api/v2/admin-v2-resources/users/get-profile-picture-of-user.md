# Get Profile Picture Of User

Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:admin-read. Path parameters. A Foundry User ID. Response body. The user's profile picture in binary format. The format is the original format uploaded by the user. The response will contain a Content-Type header that can be used to identify the media type. Examples. Error responses.
