# Get Markings User

Retrieve Markings that the user is currently a member of. Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:admin-read. Path parameters. A Foundry User ID. Response body. The markings that the user has access to. The user will be able to access resources protected with these markings. This includes organization markings for organizations in which the user is a guest member. Examples. Error responses.
