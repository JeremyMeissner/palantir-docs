Get User. Get the User with the specified id. Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:admin-read. Path parameters. A Foundry User ID. Query parameters. Present status of user. Enum values: ACTIVE, DELETED. Response body. A Foundry User ID. The Foundry username of the User. This is unique within the realm. The given name of the User. The family name (last name) of the User. The email at which to contact a User. Multiple users may have the same email address. Identifies which Realm a User or Group is a member of. The palantir-internal-realm is used for Users or Groups that are created in Foundry by administrators and not associated with any SSO provider. The RID of the user's primary Organization. This will be blank for third-party application service users. The current status of the user. Enum values: ACTIVE, DELETED. A map of the User's attributes. Attributes prefixed with "multipass:" are reserved for internal use by Foundry and are subject to change. Additional attributes may be configured by Foundry administrators in Control Panel and populated by the User's SSO provider upon login. Examples. Error responses.
