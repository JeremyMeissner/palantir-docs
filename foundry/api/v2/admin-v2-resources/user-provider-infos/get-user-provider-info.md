# Get User Provider Info

Get the UserProviderInfo. Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:admin-read. Path parameters. A Foundry User ID. Response body. The ID of the User in the external authentication provider. This value is determined by the authentication provider. At most one User can have a given provider ID in a given Realm. Examples. Error responses.
