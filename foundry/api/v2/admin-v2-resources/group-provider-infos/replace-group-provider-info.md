# Replace Group Provider Info

Replace the GroupProviderInfo. Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:admin-write. Path parameters. A Foundry Group ID. Request body. The ID of the Group in the external authentication provider. This value is determined by the authentication provider. At most one Group can have a given provider ID in a given Realm. Response body. The replaced GroupProviderInfo. The ID of the Group in the external authentication provider. This value is determined by the authentication provider. At most one Group can have a given provider ID in a given Realm. Examples. Error responses.
