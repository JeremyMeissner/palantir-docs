Get Group Provider Info. Get the GroupProviderInfo. Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:admin-read. Path parameters. A Foundry Group ID. Response body. The ID of the Group in the external authentication provider. This value is determined by the authentication provider. At most one Group can have a given provider ID in a given Realm. Examples. Error responses.
