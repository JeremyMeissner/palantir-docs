Create Streaming Dataset. Warning. This endpoint is in preview and may be modified or removed at any time. To use this endpoint, add preview=true to the request query parameters. Creates a streaming dataset with a stream on the specified branch, or if no branch is specified, on the default branch ('master' for most enrollments). For more information on streaming datasets, refer to the streams user documentation. Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:streams-write. Query parameters. Enables the use of preview functionality. Request body. The unique resource identifier (RID) of a Folder. The Foundry schema to apply to the new stream. The branch to create the initial stream on. If not specified, the default branch will be used ('master' for most enrollments). The number of partitions for the Foundry stream. Generally, each partition can handle about 5 mb/s of data, so for higher volume streams, more partitions are recommended. If not specified, 1 partition is used. This value cannot be changed later. A conceptual representation of the expected shape of the data for a stream. HIGH_THROUGHPUT and LOW_LATENCY are not compatible with each other. Defaults to LOW_LATENCY. Enum values: LOW_LATENCY, HIGH_THROUGHPUT. Whether or not compression is enabled for the stream. Defaults to false. Response body. The Resource Identifier (RID) of a Dataset. The unique resource identifier (RID) of a Folder. Examples. Error responses.
