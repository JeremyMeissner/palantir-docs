Upload Version. Upload a new version of the Website. Third-party applications using this endpoint via OAuth2 must request the following operation scope: third-party-application:deploy-application-website. Path parameters. An RID identifying a third-party application created in Developer Console. Query parameters. The semantic version of the Website. Request body. The zip file that contains the contents of your application. For more information, refer to the documentation user documentation. Response body. The semantic version of the Website. Examples. Error responses.
