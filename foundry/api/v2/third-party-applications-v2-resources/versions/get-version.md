# Get Version

Get the Version with the specified version. Third-party applications using this endpoint via OAuth2 must request the following operation scope: third-party-application:deploy-application-website. Path parameters. An RID identifying a third-party application created in Developer Console. The semantic version of the Website. Response body. The semantic version of the Website. Examples. Error responses.
