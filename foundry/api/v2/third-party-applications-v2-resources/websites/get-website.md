Get Website. Get the Website. Third-party applications using this endpoint via OAuth2 must request the following operation scope: third-party-application:deploy-application-website. Path parameters. An RID identifying a third-party application created in Developer Console. Response body. The version of the Website that is currently deployed. The subdomains from which the Website is currently served. Examples. Error responses.
