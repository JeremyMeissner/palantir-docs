# Get Status Sql Query

Gets the status of a query. Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:sql-queries-read. Path parameters. The unique identifier for a query. Note that query IDs are not URL-safe and must be URL-encoded when used in API endpoints. Response body. Examples. Error responses.
