# Delete Branch

Deletes the Branch with the given BranchName. Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:datasets-write. Path parameters. The Resource Identifier (RID) of a Dataset. The name of a Branch. Examples. Error responses.
