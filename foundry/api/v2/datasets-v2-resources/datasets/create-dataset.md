# Create Dataset

Creates a new Dataset. A default branch - master for most enrollments - will be created on the Dataset. Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:datasets-write. Request body. The unique resource identifier (RID) of a Folder. Response body. The created Dataset. The Resource Identifier (RID) of a Dataset. The unique resource identifier (RID) of a Folder. Examples. Error responses.
