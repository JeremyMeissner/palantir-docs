Get Dataset Health Checks. Warning. This endpoint is in preview and may be modified or removed at any time. To use this endpoint, add preview=true to the request query parameters. Get the RIDs of the Data Health Checks that are configured for the given Dataset. Third-party applications using this endpoint via OAuth2 must request the following operation scopes: api:data-health-read api:datasets-read. Path parameters. The Resource Identifier (RID) of a Dataset. Query parameters. The name of the Branch. If none is provided, the default Branch name - master for most enrollments - will be used. Enables the use of preview functionality. Response body. Examples. Error responses.
