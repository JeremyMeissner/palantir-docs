# Get Mcp Server

Warning. This endpoint is in preview and may be modified or removed at any time. To use this endpoint, add preview=true to the request query parameters. Get details of an MCP server. Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:ontology-mcp-read. Path parameters. The RID of the MCP server. Query parameters. Enables the use of preview functionality. Response body. The RID of the MCP server. The display name of the MCP server. An LLM-oriented description of the MCP server. Examples. Error responses.
