Create Folder. Warning. This endpoint is in preview and may be modified or removed at any time. To use this endpoint, add preview=true to the request query parameters. Creates a new Folder. Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:filesystem-write. Query parameters. Enables the use of preview functionality. Request body. The parent folder Resource Identifier (RID). For Projects, this will be the Space RID and for Spaces, this value will be the root folder (ri.compass.main.folder.0). The display name of the Resource. Response body. The created Folder. The unique resource identifier (RID) of a Folder. The display name of the Resource. The description associated with the Folder. The documentation associated with the Folder. The full path to the resource, including the resource name itself. A folder can be a regular Folder, a Project or a Space. Enum values: FOLDER, SPACE, PROJECT. The Foundry user who created this resource. The Foundry user who last updated this resource. The time at which the resource was created. The time at which the resource was most recently updated. The trash status of the Folder. If trashed, this could either be because the Folder itself has been trashed or because one of its ancestors has been trashed. Enum values: DIRECTLY_TRASHED, ANCESTOR_TRASHED, NOT_TRASHED. The parent folder Resource Identifier (RID). For Projects, this will be the Space RID and for Spaces, this value will be the root folder (ri.compass.main.folder.0). The Project Resource Identifier (RID) that the Folder lives in. If the Folder is a Space, this value will not be defined. The Space Resource Identifier (RID) that the Folder lives in. If the Folder is a Space, this value will be the same as the Folder RID. Examples. Error responses.
