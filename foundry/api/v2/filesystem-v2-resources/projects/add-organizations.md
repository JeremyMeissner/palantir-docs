# Add Organizations

Warning. This endpoint is in preview and may be modified or removed at any time. To use this endpoint, add preview=true to the request query parameters. Adds a list of Organizations to a Project. Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:filesystem-write. Path parameters. The unique resource identifier (RID) of a Project. Query parameters. Enables the use of preview functionality. Request body. Examples. Error responses.
