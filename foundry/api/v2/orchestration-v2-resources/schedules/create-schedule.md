# Create Schedule

Warning. This endpoint is in preview and may be modified or removed at any time. To use this endpoint, add preview=true to the request query parameters. Creates a new Schedule. Warning. If the schedule is created in user-scoped mode, outputs to build will be discovered based on resources that the user has access to. If the user's permissions change later, this could change the outputs that will be built or cause builds to fail. Consider using a project-scoped schedule instead. Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:orchestration-write. Query parameters. Enables the use of preview functionality. Request body. The schedule trigger. If the requesting user does not have permission to see the trigger, this will be empty. The boundaries for the schedule build. Response body. The created Schedule. The RID of a Schedule. The RID of the current schedule version. The time at which the resource was created. The Foundry user who created this resource. The time at which the resource was most recently updated. The Foundry user who last updated this resource. The schedule trigger. If the requesting user does not have permission to see the trigger, this will be empty. The boundaries for the schedule build. Examples. Error responses.
