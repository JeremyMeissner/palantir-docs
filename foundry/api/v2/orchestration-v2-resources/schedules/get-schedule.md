Get the Schedule with the specified rid. Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:orchestration-read. Path parameters. The RID of a Schedule. Query parameters. Enables the use of preview functionality. Response body. The RID of a Schedule. The RID of the current schedule version. The time at which the resource was created. The Foundry user who created this resource. The time at which the resource was most recently updated. The Foundry user who last updated this resource. The schedule trigger. If the requesting user does not have permission to see the trigger, this will be empty. The boundaries for the schedule build. Examples. Error responses.
