# Run Schedule

Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:orchestration-write. Path parameters. The RID of a Schedule. Response body. The RID of a schedule run. The RID of a Schedule. The RID of a schedule version. The time at which the schedule run was created. The Foundry user who manually invoked this schedule run. Automatic trigger runs have this field set to empty. The result of triggering the schedule. If empty, it means the service is still working on triggering the schedule. Examples. Error responses.
