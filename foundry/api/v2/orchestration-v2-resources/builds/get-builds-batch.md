# Get Builds Batch

Execute multiple get requests on Build. Users are allowed to make a maximum of 4 requests per second and 25 concurrent requests. The maximum batch size for this endpoint is 100. Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:orchestration-read. Request body. Response body. Examples.
