# Get Check

Warning. This endpoint is in preview and may be modified or removed at any time. To use this endpoint, add preview=true to the request query parameters. Get the Check with the specified rid. Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:data-health-read. Path parameters. The unique resource identifier (RID) of a Data Health Check. Query parameters. Enables the use of preview functionality. Response body. The unique resource identifier (RID) of a Data Health Check. Configuration of a check. A note about why the Check was set up. The user that created the Check. The timestamp when the Check was last updated. Examples. Error responses.
