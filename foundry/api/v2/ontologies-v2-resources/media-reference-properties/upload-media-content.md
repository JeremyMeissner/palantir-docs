Upload Media Content. Warning. This endpoint is in preview and may be modified or removed at any time. To use this endpoint, add preview=true to the request query parameters. Uploads a media item to the media set which backs the specified property. The property must be backed by a single media set and branch, otherwise an error will be thrown. The body of the request must contain the binary content of the file and the Content-Type header must be application/octet-stream. Third-party applications using this endpoint via OAuth2 must request the following operation scopes: api:ontologies-read api:ontologies-write. Path parameters. The API name or RID of the Ontology. To find the API name or RID, use the List Ontologies endpoint or check the Ontology Manager. The API name of the object type. To find the API name, use the List object types endpoint or check the Ontology Manager. The API name of the media reference property. To find the API name, check the Ontology Manager or use the Get object type endpoint. Query parameters. A path for the media item within its backing media set. Required if the backing media set requires paths. A boolean flag that, when set to true, enables the use of beta features in preview mode. Request body. Response body. The media reference for the uploaded media. The media type of the file or attachment. Examples: application/json, application/pdf, application/octet-stream, image/jpeg. A union of the types supported by media reference properties. Examples.
