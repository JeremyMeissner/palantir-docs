# Get Attachment Property Content By Rid

Get the content of an attachment by its RID. The RID must exist in the attachment array of the property. Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:ontologies-read. Path parameters. The API name or RID of the Ontology. To find the API name or RID, use the List Ontologies endpoint or check the Ontology Manager. The API name of the object type. To find the API name, use the List object types endpoint or check the Ontology Manager. The primary key of the object containing the attachment. The API name of the attachment property. To find the API name for your attachment, check the Ontology Manager or use the Get object type endpoint. The RID of the attachment. Query parameters. The package rid of the generated SDK. The version of the generated SDK. Response body. Success response. Examples.
