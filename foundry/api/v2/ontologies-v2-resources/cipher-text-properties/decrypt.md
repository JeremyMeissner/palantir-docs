Decrypt. Decrypt the value of a ciphertext property. Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:ontologies-read. Path parameters. The API name or RID of the Ontology. To find the API name or RID, use the List Ontologies endpoint or check the Ontology Manager. The API name of the object type. To find the API name, use the List object types endpoint or check the Ontology Manager. The primary key of the object with the CipherText property. The API name of the CipherText property. To find the API name for your CipherText property, check the Ontology Manager or use the Get object type endpoint. Response body. Success response. Examples.
