Supported resources. The vast majority of Foundry resource types can be included as outputs when creating a product. For packaging constraints and details specific to each resource type, refer to the resource's Marketplace documentation. For example, see the Marketplace documentation for Action types or Automations. Unsupported resources. If a resource is unsupported, the resource will show in the draft with an error. Unsupported resources must be removed from the draft before publishing. All unsupported resources can be removed by using the Actions dropdown and selecting Drop all failed to package. A non-exhaustive list of unsupported resources is below: Data Connection sources. Code Workbook workbooks. Fusion sheets.
