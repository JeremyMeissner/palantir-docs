Add sync to a Marketplace product. Use Foundry DevOps to include your Data Connection syncs in Marketplace products for other users to install and reuse. Learn how to create your first product. Supported features. Both standard syncs and streaming syncs can be included in Marketplace products. Adding Data Connection syncs to products. To add a Data Connection sync to a product, first create a product. Add outputs, then select the Data connection sync output type. Once you have selected a Data Connection source, you can select which syncs you would like to include in your product.
