# Core display widgets

Object Table: Renders an object set in a tabular display with each object displayed as a row. Object List: Renders an object set in a list display with each object displayed as a card. Object View: Renders Object Explorer’s object view for a single object. Property List: Displays a configurable list of properties from a given object set. Links: Renders the link types and linked objects of an object set in expandable and collapsible sections. Object Set Title: Displays a summary of a given object set as a title. Header text: Renders two rows of text optimized for display in a header.
