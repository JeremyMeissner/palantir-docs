Commands. Commands in Workshop provide a common interface that you can use to declare and execute operations in other Palantir platform applications embedded in a module. Additionally, you can create AIP Chatbots (formerly known as AIP Agents) to execute operations that commands can read and write from other applications. Commands can be used independently of, or in tandem with, the App Pairing widget to orchestrate cross-application operations across Palantir applications. Learn more about commands.
