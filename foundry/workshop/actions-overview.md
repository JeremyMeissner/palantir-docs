# Actions

Actions in Foundry allow users to easily define meaningful building blocks for creating, editing, deleting, and linking object data. For example: A "Create New Flight" Action creates a new Flight object and sets the Flight Number, Time of Departure, Origin, and Destination properties on that object. A "Delay Flight" Action modifies an existing Flight object to delay its Time of Departure property. An "Assign To Flight" Action links a Flight object to a Passenger object. To learn how Actions can be used in Workshop, see Use an Action within Workshop. Defining an Action. For a tutorial on how to define an action type, see the Actions tutorial.
