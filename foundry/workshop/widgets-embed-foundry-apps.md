Embed Foundry apps. Iframe: Embed a custom widget URL or Slate application via iframe. Derived series: Embed a derived series management space to create, update, and discover derived series. Map Application Template: Display an existing geospatial template created in the Map application. Notepad - Embedded Document: Embed a configured Notepad document in either read-only or edit mode. Quiver Dashboard: Render an embedded dashboard constructed and published from Quiver. Vertex Graph: Display an existing graph, graph template, or diagram created in the Vertex application. Workshop: Embedded Module: Embed another Workshop module as a widget.
