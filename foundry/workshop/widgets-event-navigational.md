# Workshop • Event-trigger & navigational widgets • Overview • Palantir

Event-triggering / navigational widgets. Button Group: Trigger Actions, Workshop Events, URLs, and export via buttons with configurable styles. Comments: Enables collaboration in a Workshop module. Media Uploader: Upload media files to Foundry and trigger Actions using uploaded files as input. Tabs: Display tabs that can trigger Workshop Events to navigate throughout pages and layers of a module when triggered. Inline Action: Renders an inline action form or table on an action type from the Ontology. Other widgets, such as the Metric Card, also support triggering commands, actions, or events through specific configuration options like the Interactive metric setting.
