# Debug

Use the debugger tool in Code Repositories to examine the behavior of your unit test while it runs. Set breakpoints to pause the execution of the unit test in order to examine variables, and understand functions and libraries. For detailed information on setting breakpoints, running the debugger, and examining variables, refer to the function debugging documentation.
