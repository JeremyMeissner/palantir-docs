# Create Target Intel Target

Create Intel on Target by RID. Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:target-write. Path parameters. The unique identifier for a Target. Request body. Enum values: SIGINT, OSINT, IMINT, ELINT, HUMINT, OTHER, ALL_SOURCE, GEOINT, OPIR, FMV, COMINT. A circle representing the area a target is located. Response body. An empty response object indicating the request was successful. Examples. Error responses.
