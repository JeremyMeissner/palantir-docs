Get object. Gets a specific object with the given primary key. Path parameters. The primary key of the requested object. Response body. Success response. The primary key/unique identifier of an object, useful for interacting with Gotham APIs to load and mutate objects. The title of an object, which represents a display-friendly String of what the object represents. The name of the object in the API - also called the Object Type URI. A map of the property values of the object. Represents a time interval by its start and end datetime. TimeInterval is generally used when an Object has a meaningful start and/or end datetime, such as an event. For example, a Meeting might have start and end datetimes corresponding to when the meeting began and ended. Examples.
