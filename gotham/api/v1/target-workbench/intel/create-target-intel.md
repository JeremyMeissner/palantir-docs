# Create Intel On a Target

Create Intel on Target by RID. Path parameters. Target RID. Query parameters. Represents a boolean value that restricts an endpoint to preview mode when set to true. Request body. Enum values: SIGINT, OSINT, IMINT, ELINT, HUMINT, OTHER, ALL_SOURCE, GEOINT, OPIR, FMV, COMINT. A circle representing the area a target is located. Response body. Success response. Examples.
