The Fires warfighting function comprises the set of systems and tasks necessary to deploy lethal and non-lethal actions on a given target with the purpose of disrupting enemy capabilities and enabling friendly mission command and control. Targeting - or the process of identifying, selecting, and prioritizing the appropriate response to an enemy target - ensures the precise impact of fires-related actions by integrating [intelligence](/docs/defense-osdk/api/intelligence/overview/about/) to engage targets at the right time and place with the correct personnel and materiel.

## Targeting and Fires interfaces in the Defense OSDK

Modeled as a distinct domain within the Defense OSDK, ontology types within *Targeting and Fires* represent targets, fire support coordination measures (FSCMs), operational assessments, and their interrelationships. [Interface link type constraints](/docs/foundry/interfaces/interface-link-types-overview) define the object-to-object relationship across object types that implement an Intelligence interface.
